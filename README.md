# Як працює веб: майстер-клас для дітей

Статичний сайт для онлайн-воркшопу (діти 9-11 років).

- `index.html`: головна сторінка «Зламай сайт» (вправа з «Дослідити»).
- `editor.html`: другий крок, редактор героя (вибір героя, поля HTML, CSS, JS) і міні-квіз.

Без сервера, cookies, аналітики та зовнішніх бібліотек.
